How the studio works

Three things every Keelwright tool gets right.

01

Local by default

Your files and your browsing stay on your computer. If a tool ever needs to talk to a service, it says so up front and asks first.

02

Open formats out

What you get back is plain files in formats other tools already understand: JSON tokens, CSS, Markdown, HTML. No lock-in, nothing to export later.

03

Built to be read

Every output is meant to be opened and understood by a person or an AI assistant, with the reasoning and the confidence behind each value written down.
